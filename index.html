📖 HOW TO GET YOUR GROQ API KEY

Follow these simple steps to get your free Groq API key:

  1. Go to the official Groq website: https://console.groq.com/keys
  2. Click Sign Up — you can use your Google account, GitHub account, or email address to register
  3. If you already have an account, simply click Log In
  4. Once logged in, look for and click the Create API Key button
  5. Enter any name you like (for example: "JARVIS AI"), then click Submit or Create
  6. Copy your API key immediately! It will only be shown once — do not close or refresh the page before copying
  7. Paste the key into the input box above, then click SAVE KEY to start using JARVIS

⚠️ IMPORTANT NOTE: Never share or expose your API key publicly. This key is linked to your personal account.
